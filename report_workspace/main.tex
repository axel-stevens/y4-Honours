\subsubsection*{Spelling and Grammar}
The project team used ChatGPT (https://chat.openai.com/) and Claude (https://claude.ai/) for this Progress Report to check spelling and grammar in selected text drafted by the team. The use of AI tool was limited to identifying spelling and grammar errors. The tools were not used to draft new report sections, produce summaries or paraphrases, restructure the report, interpret results, draw conclusions. The project team reviewed all suggestions before making any changes and retained copies of the original text submitted to the AI tools.

The following prompt was used in May 2026:

\begin{quote}
Please review the following paragraph and identify spelling and grammar errors only. Do not rewrite the text, change the meaning, improve the flow, shorten sentences, add content, or make style or substantive editing suggestions.
\end{quote}

Initials of group members who used this support: HL, LT, KM, AS.

\subsubsection*{Research Technical Support}

The project team used Claude Code to analyse the legacy MATLAB driver, implement radar commands, and produce code documentation. All code and documentation generated by AI underwent human review and approval. AI use in this form was approved verbally by Dr Brian Ng. The following prompt was used in April 2026:

\begin{quote}
Document all functions in the following file using Doxygen-style comments:

\begin{verbatim}
C:\Users\eliza\SDR_main\SDR_main\linux\src\UsbDevice.cpp
\end{verbatim}

\text{Documentation requirements:}
\begin{itemize}
    \item Add a Doxygen comment block above every function definition.
    \item Include:
    \begin{itemize}
        \item \texttt{@brief}
        \item \texttt{@param} for all parameters
        \item \texttt{@return} where applicable
        \item \texttt{@note} or \texttt{@warning} if relevant
    \end{itemize}
    \item Keep descriptions concise but technically clear.
\end{itemize}
\end{quote}

Initials of group members who used this support: HL
